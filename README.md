# Parking App – Flutter

Кроссплатформенное приложение для поиска и бронирования парковочных мест в городе.  
Реализована адаптивная верстка для телефонов, планшетов и десктопов, офлайн-доступ и симуляция оплаты.

## Возможности

- **Просмотр парковок** – главный экран с сеткой карточек, количество свободных мест и цена за час.
- **Детали парковки** – подробная информация о выбранной парковке.
- **Бронирование** – выбор даты, времени и длительности с автоматическим уменьшением числа свободных мест.
- **Оплата** – форма ввода данных карты с эмуляцией платежа через REST API.
- **Избранное** – добавление парковок в избранное, быстрый доступ к ним.
- **История бронирований** – список активных и отменённых броней с возможностью отмены.
- **Статистика** – круговая диаграмма занятых/свободных мест по всем парковкам.
- **Аутентификация** – простой вход по email и паролю с сохранением сессии.
- **Офлайн-режим** – кеширование данных через Hive и локальную БД SQLite.
- **Адаптивный UI** – Material 3, поддержка телефона, планшета и десктопа (NavigationRail, BottomNavigationBar, Drawer).
- **Тёмная и светлая тема** – переключение с сохранением выбора.
- **Локализация** – русский, английский, белорусский языки.
- **Уведомления** – локальные уведомления о бронировании и результате оплаты.

## Технологии

- **Язык**: Dart
- **Фреймворк**: Flutter
- **Управление состоянием**: flutter_bloc, equatable
- **Навигация**: go_router
- **Сеть**: dio
- **Локальное хранилище**: 
  - SQLite (sqflite) – основная БД (парковки, брони, платежи)
  - Hive – кеширование данных для офлайн-доступа
  - SharedPreferences – тема, данные сессии
- **Графики**: fl_chart
- **Уведомления**: flutter_local_notifications, fluttertoast
- **Адаптивность**: кастомные виджеты + LayoutBuilder
- **Локализация**: flutter_localizations, intl
- **Тестирование**: mocktail (моки)
- **Сборка**: Gradle (Android), Xcode (iOS), GitHub Actions (опционально)

## Запуск

### Требования
- Flutter SDK (≥3.11.5)
- Эмулятор или устройство с API 21+ (Android) / iOS 12+

### Установка
```bash
git clone https://github.com/Kotionolik/PMVS_Lab9_Task1.git
cd PMVS_Lab9_Task1
flutter pub get
flutter run
```

### Сборка под десктоп (Windows/Linux/macOS)
```bash
flutter run -d windows   # или linux, macos
```
